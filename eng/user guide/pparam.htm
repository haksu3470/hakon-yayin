PROGRAMMING PARAMETERS

 

P00     : FIRST SECURITY CODE DEFAULT VALUE IS “00”

P01     : SECOND SECURITY CODE DEFAULT VALUE IS “00”

P02     : AFTER THE ELEVATOR MOTOR START IT DETERMINE  ITS SPEED AND TURNING

TORQUE.   HIGH VALUE GIVE,  LOW SPEED HIGH POWER AND VICE VERSA. DEFAULT VALUE IS 40.

P03     : AFTER THE ELEVATOR DOOR MOTOR START IT DETERMINE  ITS SPEED AND TURNING

TORQUE.   HIGH VALUE GIVE,  LOW SPEED HIGH POWER AND VICE VERSA. DEFAULT VALUE IS 10.

P04     : IT DETERMINE ELEVATOR`S PRE-TORQUE.  HIGH VALUE GIVES LOW SPEED AND HIGH TORQUE.   DEFAULT VALUE IS 60.

P05     : IT DETERMINE ELEVATOR DOOR MOTOR`S PRE-TORQUE.  HIGH VALUE GIVES LOW SPEED AND HIGH TORQUE.   DEFAULT VALUE IS 25.

P06     : IT DETERMINE DOOR OPENING TIME STEP.  STEP VALUE IS 0.45 SECONDS TIME FOUND BY  MULTIPLYING  WITH ADJUSTED VALUE.   STEP VALUE IS 0.45 SECONDS. DEFAULT VALUE IS 15 SECONDS .  MAXIMUM VALUE IS 15 SECONDS.

 P07    : IT DETERMINES THE TIME VALUE AFTER WHICH KTS WILL BECOME ACTIVE WHEN ELECTRIC CUT OFF.  DEFAULT VALUE 1 SECOND.  MAXİMUM VALUE 99 SECONDS.

P08     : IT DETERMINE THE TIME TO REACH TO THE  FLOOR.  IT SHOULD BE SET FOR THE DISTANCE BETWEEN THE FLOORS. STEP VALUE IS 2 SECONDS AND DEFAULT VALUE 120 SECONDS, MAXIMUM VALUE IS 198 SECONDS.

P09     : IT DETERMINES STOP TIME AFTER THE SIGNAL FROM THE FLOOR COMES.  WHEN KTS IS PUT INTO USE IT WORKS UNTIL IT COMES TO THE FLOOR.  BUT KTS WORKING SPEED UNDER THE MOTOR`S NORMAL SPEED MAY SEE THE MAGNETIC ON THE FLOOR AND CAN`T REACH THE FLOOR. AFTER THE FLOOR SIGNAL CAME IT`S CAN BE SET AND YOU CAN STOP IT AT THE FLOOR.STEP VALUE 0.35  DEFAULT VALUE IS  0,35 SECOND.  MAXIMUM VALUE 35 SECOND.

P10     : IF THE AUTOMATIC DOOR IS WORKING WITH 220V AC  (LIKE COLLAPSIBLE DOOR) THIS PARAMETER MUST BE 1.  DC (AS DIAGRAM) ,380V AC (LIKE SELCOM) OR IF THERE IS NO AUTOMATIC DOOR ON ELEVATOR IT MUST BE “0”.

P11     : IF ELEVATOR COMES TO THE LEVEL IN THE LEVEL BISTABLE SWITCH IS OPEN OR CLOSE AS THE CONTROL PANEL. THIS PARAMETER MUST BE IF BISTABLE SWITCH  CLOSED “1” IF BISTABLE SWITCH OPEN “0”

P12     : IT SHOWS THE AUTOMATIC DOOR. IF THERE IS AUTOMATIC DOOR 1 IF NOT 0.

P13     : IT SHOWS THE TYPE OF AUTOMATIC DOOR. IF AUTOMATIC DOOR IS 380V AC IT SHOULD BE “1” IF NOT “0”.

P14     : IN EXPERIMENT WHEN KTS PUT INTO USE IT IS FOR GIVING THE WAY. IF FIRST WAY UP 1  IF DOWN “0”.  IF ADJUSTMENT NOT TRUE IN THE DOWN AND UP LIMIT SWITCH KTS WILL TRY ON THE

REVERSE WAY.

P15     : DOOR MOTOR TRIES TO FIRST DIRECTION.  FACTORY VALUE IS “0” BUT AFTER  CONNECTION WHEN PUT INTO USE WANT TO CLOSE YOU SHOULD DO “1”.

P16     : WHEN ELEVATOR IS IN THE UPPER OR LOWER LIMIT SWITCH.   IF BISTABLE SWITCH  CLOSED “1” IF BISTABLE SWITCH OPEN “0”

P17     : RE-INSTALL FACTORY VALUES.  SELECT 1 AND PRESS ENTER  IT AUTOMATICLY RE-INSTALL FACTORY DEFAULT VALUES.

P18     : IF REVISION MODE SWITCH IS OPEN IN THE NORMALLY MODE THIS PARAMETER MUST BE  “0” ELSE  “1”
