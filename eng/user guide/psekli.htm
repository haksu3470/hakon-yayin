ENTERING THE PROGRAMMING MODE

 

 Entering programming mode or to quit programming mode you must touche up and down button (on the control panel) together  for 3 seconds.

The characters on the display shown  if three characters it shows the level , if two characters it  shows  data of the level.

To change the parameters  the security codes  C00 and C01 respectively entered correctly. If you can not enter codes correctly you can not change the parameters.for the safety of the system there are two security code.

 

ENTERING THE SECURITY CODE

            When you see the C00 on the display press the enter button once. You see 00 on the display . If you didn’t change the security codes  and press the enter button again . If you have changed the security codes you can use the down or up button to  enter old security codes (which you know respectively and correctly). If you do the same process C01 you can reach the parameters.

 

CHANGING THE SECURITY CODES

            After you reach the parameters C00 is your first security code, C01 is the second security code.

To change P00 when there is P00 on the display press the enter button once. You  will see old security code on the display.  You can change the code with up or down buttons. Then press enter button to save it. If you want to change P01 you can  do the same process  for it. When you quit the programming mode all the parameters are saved.
